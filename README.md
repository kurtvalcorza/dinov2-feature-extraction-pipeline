# DINOv2 Feature Extraction Pipeline

DIMER inference wrapper for **`timm/vit_small_patch14_dinov2.lvd142m`** — self-supervised image feature extraction (384-d embeddings, no classifier head) — pinned to an immutable Hugging Face revision and loaded only from a digest-verified local snapshot.

## Upstream alignment

- Model: `timm/vit_small_patch14_dinov2.lvd142m` (DINOv2 ViT-S/14, 22.1 M parameters, LVD-142M pre-training)
- Revision: `4610ca143709d58a633b6397a74412c2c3842454`
- Upstream weight license: Apache-2.0 (upstream re-licensed from CC-BY-NC-4.0 on 2023-08-31; the `cc-by-nc-4.0` in the snapshot `config.json` is a stale timm field — see `docs/WEIGHTS.md`)
- Upstream task: image feature backbone, fixed 518×518 input, `num_classes = 0`, class-token pooling
- Repository adaptation: bounded supervised adaptation on `{id, image, label}` records (`adapt`) — a linear probe on the frozen features (frozen policy) and an optional unfreeze of the last transformer blocks selected against it by validation log-loss (unfrozen policy) — measured by held-out accuracy and macro-F1 (`evaluate`, `knn_baseline`, `majority_baseline`); `embed` is unchanged and adds L2 normalisation of the pooled vector; the base weights are never redistributed and the adapter is a tutorial output

## Quick start

```python
from PIL import Image
from dinov2_feature_extraction_pipeline import DINOv2FeatureExtractionPipeline

pipe = DINOv2FeatureExtractionPipeline.from_pretrained()          # cuda:0 if available, else cpu
result = pipe.embed([Image.open("a.jpg"), Image.open("b.jpg")])
a, b = result["embeddings"]                                       # two lists of 384 floats, unit L2 norm
print(result["dim"], result["pooling"], sum(x * y for x, y in zip(a, b)))   # 384 cls <cosine similarity>

# adaptation: the pinned iNaturalist bird photographs (fetched and digest-checked at run time), floors, two policies
from dinov2_feature_extraction_pipeline import fetch_sample_dataset

splits = fetch_sample_dataset()                                   # 108 / 24 / 48 {id, image, label} records, 6 species
print(pipe.knn_baseline(splits["train"], splits["test"])["accuracy"])   # frozen features, no training
pipe.adapt(splits["train"], splits["validation"], trainable_blocks=0)   # frozen policy: linear probe
print(pipe.evaluate(splits["test"])["accuracy"])
pipe.adapt(splits["train"], splits["validation"])                     # unfrozen policy: last two blocks, selected on validation
print(pipe.adapter["policy"], pipe.evaluate(splits["test"])["accuracy"])
print(pipe.classify(splits["test"][0]["image"])["labels"])
pipe.save_artifact("outputs/dinov2_adapter")                      # adapter.safetensors + manifest.json
reloaded = DINOv2FeatureExtractionPipeline.from_artifact("outputs/dinov2_adapter")
```

There is no label, no score and no metric helper: an embedding has no intrinsic accuracy. Evaluate on your own downstream task (retrieval, clustering, a linear probe) and calibrate any similarity threshold on your own labelled pairs.

## Weights layout

```
weights/vit-small-dinov2/
  dimer-base-manifest.json   # modelId, revision, per-file bytes + sha256 (verified on every load)
  config.json                # timm pretrained_cfg: input size 518, mean/std, num_classes 0, global_pool token
  model.safetensors          # 88240510 bytes, git-ignored
weights/inat-birds/          # git-ignored run-time cache of the 180 pinned CC0 photographs (19 MB)
```

`from_pretrained()` calls `verify_snapshot()` first and refuses to load if any file is missing or its SHA-256 differs from the manifest. Without a snapshot, `allow_download=True` loads from the Hub through timm's `hf-hub:timm/vit_small_patch14_dinov2.lvd142m@4610ca143709d58a633b6397a74412c2c3842454` form; the default is to refuse. To stage the snapshot: `hf download timm/vit_small_patch14_dinov2.lvd142m --revision 4610ca143709d58a633b6397a74412c2c3842454 --local-dir weights/vit-small-dinov2`, then write the manifest.

## Tutorial

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/kurtvalcorza/dinov2-feature-extraction-pipeline/blob/main/tutorials/dinov2_feature_extraction_colab.ipynb)

`tutorials/dinov2_feature_extraction_colab.ipynb` is declared `E2E` (mode `GUIDED`) under DIMER Notebook Specification 2.0 and is **standalone** (§4): generated by `tools/build_notebook.py`, it carries the three pipeline modules (`pipeline.py`, `metrics.py`, `samples.py` — including the 180-row pinned photo table), the model identity, manifest digests and runtime pins, so the exported notebook runs without this repository (parity enforced by `tests/test_notebook_parity.py`; see `tutorials/README.md`). Its default path stages the missing `model.safetensors` with `stage_missing_files(..., allow_download=True)` and digest-verifies the snapshot, fetches the 180 digest-pinned CC0 iNaturalist photographs and draws 108 / 24 / 48 images by a seeded stratified split with `validate_dataset`, `check_split_disjoint` and `observer_overlap`, embeds three test images through the inference contract, scores the frozen features on the test split by a majority floor, a cosine 5-NN vote and a linear probe (the frozen policy), trains a bounded unfreeze of the last two transformer blocks and selects between it and the probe by validation log-loss (the unfrozen policy), scores the held-out split with the selected model (k-NN 83.3 %, probe 83.3 %, selected `unfrozen last 2 blocks + linear head` 83.3 % in the recorded run), prints predictions before and after, and exports the head plus any trained blocks as a safetensors adapter that reloads to identical probabilities. Six `outputs/` artifacts are written. BYOD (a `.zip` with `labels.csv` beside the image files) is optional and gated off by default.
